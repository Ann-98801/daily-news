# 每日早报 · 随身版

一个完全免费、不需要自己买服务器的新闻聚合小站：
后台每小时自动抓取新华社、人民日报、BBC、CNN、路透社的要闻，以及微博热搜榜，
生成一个网页，任何设备打开网址都能看（手机、平板、公司电脑都行）。

## 为什么之前的版本"只能在本机运行"

之前那个程序大概率是在浏览器里用 JavaScript 直接去访问新华社、BBC 这些网站，
这种做法会被目标网站的跨域安全策略（CORS）拦下来，只有在你自己电脑上开特殊设置时才勉强能用。

这一版把"抓取"这件事挪到了服务器端（这里用 GitHub 的免费自动化功能来充当"服务器"），
抓好的数据存成一个 `data.json` 文件放在网上，网页本身只负责读取和展示这个文件，
所以不管你用哪台设备、在哪里打开网址，都能看到内容。

## 这套方案用到的免费服务

- **GitHub Pages**：免费托管网页，给你一个类似 `https://你的用户名.github.io/仓库名/` 的网址。
- **GitHub Actions**：免费的定时任务功能，每小时自动跑一次抓取脚本。

全程不用花一分钱，也不用买、配置任何服务器。

## 部署步骤（跟着做，大约10分钟）

### 第一步：注册 GitHub 账号
如果还没有，去 https://github.com 免费注册一个。

### 第二步：新建一个仓库（Repository）
1. 登录后点右上角"+" → "New repository"
2. 仓库名随便起，比如 `news-brief`
3. 选择 "Public"（公开，Pages 免费版需要公开仓库）
4. 点 "Create repository"

### 第三步：把这些文件上传上去
最简单的办法（不用装任何软件）：
1. 进入刚建好的仓库页面
2. 点 "Add file" → "Upload files"
3. 把我给你的这个文件夹里的所有文件和文件夹（包括 `.github` 这个隐藏文件夹）
   直接拖进网页里上传
4. 下面填写提交信息，点 "Commit changes"

> 注意：`.github` 文件夹名字前面有个点，上传时容易被忽略，
> 请确认 `.github/workflows/update.yml` 这个文件确实上传成功了
> （可以在仓库页面里点进 `.github` → `workflows` 文件夹检查）。

### 第四步：开启 GitHub Pages
1. 在仓库页面点 "Settings"
2. 左侧菜单找到 "Pages"
3. "Source" 选择 "Deploy from a branch"
4. Branch 选择 "main"，文件夹选择 "/docs"，点 "Save"
5. 等一两分钟，页面顶部会出现你的网址，形如：
   `https://你的用户名.github.io/news-brief/`

### 第五步：手动触发一次抓取（不用等一小时）
1. 在仓库页面点顶部 "Actions" 标签
2. 左侧点 "更新每日早报数据"
3. 右侧点 "Run workflow" → 再点绿色的 "Run workflow" 确认
4. 等 1-2 分钟，刷新页面看到一个绿色对勾就是成功了

### 第六步：打开你的网址看效果
把第四步拿到的网址在手机或任意设备浏览器里打开，
收藏到主屏幕，以后随时点开就是最新一次抓取的早报。

之后每小时会自动重新抓取一次，不用你再手动做任何事。

## 以后想改抓取频率、数据源？

- 抓取频率：改 `.github/workflows/update.yml` 里的 `cron: "5 * * * *"`
  （这是 UTC 时间的 cron 表达式，例如改成 `"5 */2 * * *"` 就是每2小时一次）
- 想加/换媒体源：改 `scraper/fetch_news.py`，里面每个数据源都单独写了怎么抓、
  抓哪个网址，注释里写清楚了每个来源用的是官方RSS还是必应新闻搜索兜底方案。

## 已知局限

- 新华社、人民日报、路透社目前没有稳定的官方免费接口，脚本用的是"必应新闻搜索该网站"
  这种公开搜索结果代替，摘要质量会比官方RSS（如BBC、CNN）略粗糙一些，
  少数情况下可能抓不满8条。
- 微博热搜用的是非官方接口，微博一旦调整前端结构就可能失效，
  脚本已经写了自动兜底方案，但如果两种方式都失效，
  当次会显示"该来源暂时抓取失败"，下一次定时任务通常会恢复正常。
